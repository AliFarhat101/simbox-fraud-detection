# Reports

This directory contains generated reports, figures, and tables produced during the SIMBox fraud detection project.

The original project generated multiple HTML reports during exploratory data analysis and daily profiling. These reports are not included in the public repository because they were generated from the non-public telecommunications dataset.

## Generated reports

The original local project contains generated reports including daily profiling reports and Sweetviz reports.

These files are intentionally excluded from the public repository.

They can be regenerated by running the corresponding exploratory-analysis and profiling notebooks when the required data is available.
